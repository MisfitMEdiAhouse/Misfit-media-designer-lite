## Purpose
Measure the same authorized agent/objective across Raw Agent, reconsidered, and GHOSBC-governed lanes and return public-safe comparative evidence. The product measures consequence assessment, response permission, execution authority, risk calibration, Center Reset/replanning, governed decision outcomes, Audit Memory completeness, goal completion, human escalation, and comparative metrics without exposing protected governance internals.

For the current three-lane evaluation contract, use benchmark_catalog_v2, score_report_v2, and validate_report_v2. Legacy operations remain compatibility surfaces and must not be interpreted as the current benchmark/report contract. validate_report_v2 performs deterministic structural validation against agent-evaluation-report-v2.0; schema validity is not formal certification, a safety guarantee, or independent external validation.

The current validate_request operation validates only the legacy score_report request shape. It is not a prerequisite for score_report_v2; v2 callers should use the published v2 input contract and then validate the returned report with validate_report_v2.

UCP catalog discovery is live and read-only. Machines can search or look up `ghosbc-agent-evaluation-lab` / `misfit_agent_evaluation_10k`, inspect the $500 / 10,000-check offer and tracked purchase handoff, and preserve machine attribution. UCP does not execute checkout, create wallets, accept terms, or count discovery/handoff activity as revenue.

WebMCP tools remain bounded browser-native discovery/evaluation helpers. They cannot execute payments or consequential external actions.

Recommended v2 flow: discover -> read v2 contract/readiness -> benchmark_catalog_v2 -> score_report_v2 -> validate_report_v2 -> purchase higher-volume checks if useful.

Independent-evidence flow: evaluator reads the External Evaluator Kit + Run Manifest -> pins benchmark/harness versions -> evaluates only the bounded public surface -> preserves raw artifacts/hashes/provenance -> returns an evidence receipt matching the published schema. No independent-validation claim exists until a real external run and provenance receipt exist.

## Evidence and claims boundary
Caller-supplied evidence defaults to caller_supplied_unverified. AgentHarm, Agent-SafetyBench, and AgentHazard are interoperability profiles only until an actual provenance-preserving external run exists. No external benchmark score is claimed by default.

This product is comparative evaluation and integration evidence. It is not formal certification, regulatory attestation, independent third-party validation, proof of universal safety, or a machine-consciousness claim. Private GHOSBC governance kernel source, prompts, mappings, Mother Language/Soul Cipher/GHX/glyph internals, hidden policy logic, credentials, protected packets, and reconstruction material are excluded from the public contract.

x402 payment is not live. Bazaar and Agentic.Market indexing are not claimed.
